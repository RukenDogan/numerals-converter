# Conversion Chiffres Arabes <-> Chiffres Romains

Deux scripts Python pour convertir les chiffres :  

- `arabic_to_roman.py` : convertit un nombre arabe en chiffre romain.  
- `roman_to_arabic.py` : convertit un chiffre romain en nombre arabe.
- `main.py` : script principal qui permet de choisir le type de conversion et appelle les deux modules.

**Remarque** : dans les modules, certaines lignes input() sont commentées pour pouvoir les tester indépendamment. Pour tester un module seul, il suffit de décommenter ces lignes.

## Utilisation

Lancer le script principal :  
`python main.py`


Lancer un module individuel (décommenter les lignes input() dans le module voulu, pour permettre la saisie) :
```bash
python arabic_to_roman.py
python roman_to_arabic.py
```
